# Project Statement

## Problem Statement

Create a Tic-Tac-Toe game where a human can play against an AI that makes decisions using the Minimax algorithm.

## Scope of the Project

The project focuses on implementing a basic AI opponent, handling player moves, checking game results, and providing a simple terminal-based gaming experience.

## Target Users

* Students learning Artificial Intelligence
* Beginners interested in game-based AI
* Anyone who wants to play a simple Tic-Tac-Toe game against an AI

## High-Level Features

* Human vs AI gameplay
* Minimax-based decision making
* Win and draw detection
* Input validation
* Replay option
* Command-line interface
