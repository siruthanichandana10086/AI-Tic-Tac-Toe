# AI Tic-Tac-Toe Using Minimax

## 1. Project Title

**AI Tic-Tac-Toe Using Minimax Algorithm**

## 2. Overview

This is a simple Python Tic-Tac-Toe game where a user plays against an AI. The AI uses the **Minimax algorithm** to check possible moves and choose its move.

## 3. Features

* Human vs AI gameplay
* Minimax-based AI
* Win and draw detection
* Input validation
* Replay option
* Simple terminal interface

## 4. Technologies / Tools Used

* **Python 3.x**
* **Minimax Algorithm**
* **Visual Studio Code**
* **Git & GitHub**

## 5. Installation & Running

1. Install Python 3.x.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

5. Enter `1` to start the game.
6. Enter a number from `1-9` to make a move.

## 6. Testing Instructions

* Start the program and select option `1`.
* Make valid moves using numbers `1-9`.
* Try entering an already occupied position and check the error message.
* Try invalid input and check whether the program asks again.
* Continue playing until the result is **You win, AI wins, or Draw**.
* Select `y` when asked to test the replay option.
